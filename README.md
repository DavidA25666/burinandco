# Burin & Co.

Commissioned line engravings of cars, yachts, aircraft and buildings, framed with a brass plaque.

Static draft: `public/` is served by Netlify (see `netlify.toml`). Checkout is not connected yet; the order form only shows a draft notice on submit. The plan is to reuse the Namesake Portraits order flow (Stripe Checkout, render, proof, fulfillment) once the print lab is chosen.

Images in `public/img/` are placeholder mockups of a generic coupe, not customer work.
